# M-10 · رمز التحقق ما يوصل
title_en: Verification code (OTP) not arriving
keywords: رمز التحقق, كود التحقق, الكود, الرمز ما يوصل, otp, verification code, sms, code

1. تأكد إن الخط شغال وبيه تغطية.
2. تأكد إن الرقم المكتوب هو نفس الرقم المسجل بالحساب.
3. انتظر دقيقتين قبل ما تطلب رمز جديد. الطلبات الكثيرة ورا بعض توكف الإرسال 30 دقيقة.
4. جرّب "اتصال صوتي" بدل الرسالة من نفس الشاشة.
5. إذا بعده ما يوصل، تواصل ويانا من "المساعدة".
