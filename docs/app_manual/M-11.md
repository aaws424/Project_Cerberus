# M-11 · كشف الحساب
title_en: Account statement and transaction history
keywords: كشف حساب, كشف, سجل الحركات, حركات, statement, transaction history, kashf, hisab

1. اختار "سجل الحركات" من الصفحة الرئيسية.
2. اضغط "كشف حساب" واختار الشهر أو الفترة.
3. اضغط "تنزيل PDF" أو "مشاركة".
4. كل حركة بيها رقم عملية تكدر تستخدمه إذا تواصلت ويانا.
